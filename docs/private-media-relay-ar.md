# تخزين الوسائط الخاص عبر R2

## طريقة العمل

ناقل R2 موصول بإعدادات التطبيق، لكنه متوقف افتراضياً في كل تثبيت جديد حتى تدخل بيانات حاوية خاصة وتفعّله. ناقل GitHub العام يبقى متوقفاً ولا يُستخدم كبديل تلقائي.

يرفع التطبيق JPG أو MP4 باسم عشوائي تحت `ephemeral-media/`، ثم يرسل إلى Meta رابط قراءة موقّعاً لمدة ساعة لكائن واحد. مفاتيح الوصول تُحفظ مشفّرة محلياً مع بيانات التطبيق، ولا تُقرأ من واجهة الإعدادات بعد حفظها. لا تُضمّن المفاتيح في Git أو APK.

## الخصوصية والحذف

- أبقِ `r2.dev` وأي نطاق مخصص عام متوقفين.
- الرابط الموقّع إذن قراءة لمن يملكه خلال مدة صلاحيته. هذا ليس تشفيراً طرفاً لطرف ولا ضمان خصوصية مطلقة.
- أسماء الكائنات لا تحتوي اسم الملف الأصلي أو اسم الحساب.
- بعد رجوع معرّف منشور مؤكد من Instagram، يحاول التطبيق حذف الكائن. عند فشل الحذف تبقى قاعدة العمر الاحتياطية مسؤولة عن التنظيف.
- إذا لم تُعرف نتيجة طلب Meta، لا يُحذف الكائن فوراً لأن المنصة قد تكون ما زالت تسحبه. لا يُعاد النشر تلقائياً؛ يبقى الكائن إلى أن تنظفه قاعدة العمر.
- أضف قاعدة مفعّلة لبادئة `ephemeral-media/`: حذف الكائن بعد يوم وإلغاء الرفع المجزأ غير المكتمل بعد يوم.
- انتهاء الرابط لا يحذف الملف. تقول Cloudflare إن حذف العمر يجري عادة خلال 24 ساعة بعد موعد انتهاء الكائن، وقد يتأخر أكثر.
- تغيير إعدادات الحاوية أثناء عملية نشر لا يسمح بحذف كائن من حاوية بديلة؛ يبقى التنظيف لقاعدة عمر الحاوية الأصلية.
- أقصى حجم في الناقل 1 غيغابايت، وقد تكون حدود المنصة أو واجهة الرفع المحلية أقل. هذا ليس حداً مالياً شهرياً.

## إعداد تثبيت جديد

1. وافق على شروط Cloudflare R2 والفوترة قبل إنشاء الموارد. لا تفترض أن الحصة المجانية تمنع الفواتير.
2. أنشئ حاوية Standard جديدة مخصصة للتطبيق، وتحقق من إيقاف كل طرق الوصول العام. الإعداد الحالي يستخدم الموقع التلقائي وعنوان R2 العالمي، وليس حاوية ذات اختصاص قضائي خاص.
3. أضف قاعدة العمر السابقة وتحقق من حفظها. لا تغيّر موارد أو حاويات غير مرتبطة بالتطبيق.
4. أنشئ مفتاح `Object Read & Write` محدوداً بهذه الحاوية فقط، وليس مفتاح إدارة كل الحساب.
5. من إعدادات التطبيق، أدخل معرّف حساب Cloudflare واسم الحاوية وAccess Key ID وSecret Access Key. فعّل التخزين واحفظ. الحقول الفارغة للمفاتيح تُبقي القيم المحفوظة.
6. اضغط «فحص». يرفع الفحص صورة صغيرة غير حساسة، ويتحقق من رفض القراءة غير الموقّعة ونجاح الموقّعة ثم حذف الصورة. لا يرجع رابطاً موقّعاً أو مفاتيح في نتيجة الفحص. R2 قد يعيد 400 عند غياب التوقيع، وليس بالضرورة 403.
7. يلزم اختبار مستقل لتنزيل Meta للصورة ومعالجتها باستخدام رمز API رسمي وحساب اختبار يوافق عليه صاحبه. جلسة الدخول إلى موقع Instagram لا تُعد رمز API.
8. اختبر التطبيق المثبّت على الهاتف نفسه قبل الاعتماد على النشر في الخلفية. نجاح الاختبارات المكتبية لا يثبت عمله على كل جهاز.

مكتبة `boto3` ومتطلباتها موجودة في `requirements-relay.txt` ويجب تضمينها أثناء بناء Android، لا الاعتماد على مثبّت pip المكتبي وقت التشغيل. السكربت `tools/setup_private_relay.py` اختياري لإعداد حاوية جديدة فقط؛ يعمل كتجربة دون اتصال افتراضياً ويرفض تعديل حاوية موجودة.

## الأسعار

وفق المصادر أدناه، تتضمن حصة Standard الشهرية المجانية 10 غيغابايت-شهر، ومليون عملية A، و10 ملايين عملية B. بعدها: 0.015 دولار لكل غيغابايت-شهر، و4.50 دولار لكل مليون عملية A، و0.36 دولار لكل مليون عملية B. تقرّب Cloudflare الاستخدام إلى وحدة الفوترة التالية؛ التجاوز ليس مضموناً أن يكون سنتات. لا توجد رسوم خروج لدى R2. التطبيق لا يفرض سقف إنفاق لدى Cloudflare.

تحقق من الأسعار الحالية وشروط حسابك قبل الاعتماد عليها. قد تتضمن إجراءات الاشتراك وسيلة دفع أو تحققاً أو حجزاً عليها.

## التحقق

- اختبارات محلية للمفاتيح المشفّرة، وعدم إرجاعها، وعدم العودة إلى GitHub، ومنع حذف حاوية مختلفة.
- اختبارات توقيع SDK دون شبكة، وقصر الرابط على القراءة ولمدة ساعة.
- اختبارات رفض القراءة بلا توقيع وانتهاء رابط قصير وحذف ملف غير حساس عند إعداد التخزين الحي.
- لا تُنشر المفاتيح أو روابط الاختبار الموقّعة في السجلات أو تقارير GitHub.
