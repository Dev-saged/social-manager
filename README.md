# مدير حساباتي

أداة شخصية تعمل على جوالك: تكتب منشوراً واحداً، تختار المنصات، فيُنشر على الجميع في الوقت الذي تحدده، حتى لو كان الجوال في جيبك. تكتب لك بالذكاء الاصطناعي، وترد على التعليقات والرسائل تلقائياً. تُغلَّف كتطبيق أندرويد عبر [web-to-app](https://github.com/shiaho777/web-to-app).

> خادم Flask محلي على `127.0.0.1` + واجهة HTML واحدة عربية RTL + SQLite مشفّر الاعتمادات. لا خادم وسيط ولا اشتراك.

## ما الذي يفعله

| الميزة | التفاصيل |
|---|---|
| **نشر متعدد المنصات** | نص واحد إلى X وFacebook وInstagram وYouTube وTelegram وBluesky وThreads. لكل منصة بطاقة معاينة وحد أحرف ونص مخصّص اختياري |
| **نص أو صورة أو فيديو** | الملف يُحفظ محلياً، يُنشر في موعده، ثم يُحذف تلقائياً بعد نجاح كل المنصات (وتنظيف دوري للأيتام) |
| **قرص 24 ساعة** | الحلقة تدور فتكون «الآن» دائماً في الأعلى، المنشورات المجدولة نقاط عليها، واسحب على الحلقة لاختيار الوقت. اسحب بطاقة المعاينة للأعلى للجدولة |
| **كتابة بـ Gemini** | «آخر خبر تقني» (بحث مؤسَّس بالويب مع المصدر) أو «من موضوع». نسخة مختصرة للمنصات القصيرة، وتجنّب تكرار العناوين |
| **قواعد نشر آلي** | كل يوم في أوقات تحددها يولّد التطبيق منشوراً. افتراضياً يصل مسودة تعتمدها بضغطة |
| **ردود تلقائية (Instagram)** | تعليق بكلمة مفتاحية ← رد علني + رسالة خاصة بالرابط. مطابقة عربية تفهم الألف والتاء المربوطة والتشكيل والأرقام الشرقية والسوابق (ال، بال، وال) |
| **يعمل بالخلفية ويزامن وحده** | المجدول يفحص كل 30 ثانية. عند انقطاع الإنترنت لا تُحرق المحاولات: تنتظر الشبكة وتُنشر عند عودتها |
| **أمان** | اعتمادات مشفّرة (Fernet)، الخادم يقبل `127.0.0.1` فقط، CSP صارم، لا `innerHTML` للبيانات، النسخة الاحتياطية بدون كلمات مرور |

## كيف يعمل (الهيكل)

```
static/index.html  ──fetch /api/*──▶  core/server.py (Flask)
 CONFIG • signals • قرص 24س          ├─ routes_v2.py       مجموعات النشر، الذكاء، القواعد، الصحة
 مروحة البطاقات • الأوراق السفلية     ├─ routes_replies.py  ردود التعليقات
 IndexedDB (مسودة المحرر)            └─ (قديم) تفاعل الأصدقاء بالموافقة اليدوية

core/scheduler.py (APScheduler، كل 30ث)
  ├─ publisher.run_due     يحجز الهدف قبل الإرسال (claim) ثم ينشر ثم يسجّل النتيجة
  ├─ auto_rules.run_due    يولّد منشورات القواعد اليومية
  └─ auto_reply.run        يستطلع التعليقات ويرسل الردود بتأخير عشوائي
platforms/*  محوّل لكل منصة بواجهة موحّدة + capabilities {text,image,video,max_len}
```

مبادئ الموثوقية:
- **لا تكرار أبداً**: الهدف يُحجز بحالة `publishing` قبل الإرسال؛ إن مات التطبيق في منتصفه يصير `failed` ولا يُعاد تلقائياً (قد يكون نُشر فعلاً) وتقرر أنت من واجهة الجدول.
- **استقلال الأهداف**: فشل X لا يمنع Telegram. كل منصة بحالتها ومحاولاتها.
- **أخطاء مؤقتة مقابل دائمة**: المؤقتة (شبكة، 5xx، 429) تُعاد بتأخير تصاعدي 1د، 5د، 15د، 1س، 3س. الدائمة (صلاحيات، نص مرفوض) تتوقف فوراً برسالة واضحة.
- **المنشور الفائت**: إن كان الجوال مطفأً وقت النشر يُنشر عند التشغيل داخل مهلة (12 ساعة افتراضياً، تُضبط من الإعدادات)، وبعدها يُعلَّم «فات الموعد» ولا يُنشر منشور قديم فجأة.
- القدرات تقود التحقق والواجهة: المنصة التي لا تقبل فيديو تُعطَّل تلقائياً عند إرفاق فيديو، والخادم يعيد التحقق دائماً.

## التشغيل على الحاسوب

```bash
pip install -r requirements.txt
python app.py            # http://127.0.0.1:8080
python -m unittest discover -s tests -v
```
افتح `http://127.0.0.1:8080/#test` لاختبار الواجهة الذاتي (الألوان، الدوال الأساسية، المعرّفات القديمة، توافق الإصدار مع الخادم).

## التغليف كتطبيق أندرويد (web-to-app)

1. نوع المشروع: **Python**، ملف الدخول `app.py`، المنفذ `8080` (أو مرّر `PORT`).
2. `requirements.txt` يثبّت الأساس عند التغليف (نحو 6.5MB، يلحق بمهلة 120 ثانية حتى بإنترنت بطيء). مكتبات Instagram الشخصي ويوتيوب (نحو 35MB) يثبّتها التطبيق نفسه في الخلفية عند أول تشغيل، بدون مهلة، مع انتظار عودة الإنترنت وإعادة المحاولة بتأخير تصاعدي، والملفات المكتملة تُحفظ فلا يُعاد تحميلها. تتابع التقدم من شريط أعلى الشاشة أو من «الإعدادات ← المكتبات الإضافية». إن كان إنترنتك سريعاً وقت التغليف فانسخ `requirements-full.txt` فوق `requirements.txt` ويأتي كل شيء مضمّناً.
3. **targetSdk = 28** كحد أقصى لأي تشغيل خادم (قيد المكتبة).
4. فعّل التشغيل بالخلفية (خدمة foreground) والتشغيل التلقائي عند الإقلاع.
5. في إعدادات أندرويد: **استثناء التطبيق من توفير البطارية**. بعض الشركات (Xiaomi، Huawei، Oppo، Samsung) تقتل الخدمات الخلفية بقسوة، وبدون الاستثناء قد لا يُنشر في موعده والجوال مقفل.
6. حتى يكتمل تثبيت المكتبات الإضافية تعمل بقية المنصات والجدولة فوراً، ويظهر في Instagram الشخصي ويوتيوب أنهما قيد التثبيت. التحديث: يفحص التطبيق المكتبات الإضافية أسبوعياً ويحدّثها (أو زر «تحديث» يدوياً)، ثم أعد فتح التطبيق. مكتبات الأساس تُحدَّث بإعادة التغليف.

مجلد البيانات `~/.social_manager` فيه القاعدة ومفتاح التشفير والوسائط. لا تضعه داخل APK.

## الإعداد الأول (5 دقائق)

1. **الحسابات** ← أضف الحسابات (الحقول في الجدول أدناه) واضغط «فحص الدخول».
2. **المزيد ← الإعدادات** ← الصق مفتاح Oxion (المزوّد الأساسي) ومفتاح Gemini (البديل التلقائي، والمسؤول عن الصور والفيديو). النماذج تُرشَّح تلقائياً من قائمتك الحية: الأرخص الذي يملك القدرة المطلوبة، ويمكنك تغييرها.
3. **كتابة** ← اكتب أو اضغط «اكتب لي»، اختر المنصات من الشريط السفلي، اسحب البطاقة للأعلى.

| المنصة | ما تحتاجه |
|---|---|
| Instagram رسمي (موصى به) | Access Token من «API setup with Instagram login» فقط، لحساب Creator/Business بلا صفحة فيسبوك. الوسائط عبر «مستودع الوسائط» (GitHub عام). يُجدَّد الرمز أسبوعياً |
| Instagram شخصي | اسم المستخدم + كلمة المرور أو `sessionid` (instagrapi، جلسة محفوظة، رمز التأكيد والتحقق بخطوتين يُدخلان من التطبيق) |
| Instagram Business قديم | `access_token` + `ig_user_id` عبر صفحة فيسبوك |
| Facebook شخصي | لا شيء: مشاركة نصف آلية في الموعد (Meta تمنع النشر الآلي على الملفات الشخصية) |
| Facebook صفحة | Page Access Token + Page ID |
| X | مفاتيح API الأربعة (الخطة المجانية محدودة جداً بالنشر) |
| YouTube | `client_secrets.json` وتفويض أول على الحاسوب، ثم انقل مجلد البيانات |
| Telegram | Bot Token من @BotFather + Chat ID أو @القناة (البوت مشرف في القناة) |
| Bluesky | المعرّف + App Password (من الإعدادات، وليس كلمة المرور الرئيسية) |
| Threads | Access Token + User ID من تطبيق Meta |

## الردود التلقائية: ما تحتاج معرفته

- تعمل على Instagram. الحساب الشخصي عبر instagrapi (غير رسمي)، وحساب Business عبر Graph API.
- يُستطلع التعليق الجديد كل دقيقتين تقريباً ثم يُرد بتأخير عشوائي (20 إلى 120 ثانية) وبحدود ساعية صارمة (`config.RATE_LIMITS`).
- الرد الخاص على التعليق مسموح مرة واحدة فقط لكل تعليق وخلال 7 أيام (قيد Instagram). كل رد يُحجز قبل الإرسال فلا يتكرر.
- جرّب القاعدة قبل الحفظ: اكتب تعليقاً في خانة «اختبار» وسيخبرك هل يطابق.

## حدود ومخاطر بصراحة

- **instagrapi غير رسمي**: Instagram قد يطلب تحقق أمان أو يقيّد الحساب إن أفرطت. الحدود والتأخير العشوائي مضبوطة بتحفظ، لكن الخطر لا يصفر. استخدم حساباً تتحمل مخاطرته.
- **غير مختبر على حسابات حقيقية بعد**: المحوّلات (X، Facebook، Instagram، Telegram، Bluesky، Threads) وGemini مغطاة باختبارات بمحاكاة الشبكة فقط. ابدأ بـ Telegram أو Bluesky لأنهما الأبسط، ثم بقية الحسابات، وبلّغ عن أي خطأ.
- **الذكاء**: Oxion أولاً، وأي فشل (رصيد، مفتاح، مهلة) يتحول إلى Gemini تلقائياً. Gemini: Interactions مع بديل `generateContent`، والصور والفيديو عبر Interactions (`gemini-omni-1.1-flash` للفيديو بعد إيقاف Veo).
- كل فشل يظهر بسبب مصنّف وتلميح للحل (`core/errors.py`)، ولكل منصة دليل خطوات داخل التطبيق.
- لا يمكن لأي تطبيق ضمان تشغيل خلفي على كل أجهزة أندرويد (انظر استثناء البطارية).
- النسخة الاحتياطية العادية بلا كلمات مرور. النسخة الكاملة تتضمن الحسابات والمفاتيح مشفّرة بعبارة مرور منك (PBKDF2 + Fernet).
- **الصحة والموثوقية**: نبض المجدول، استدراك الفائت عند الفتح، سجل دقة المواعيد، فحص كل مكتبة بالاستيراد الفعلي مع إعادة التثبيت.

## التحديث التلقائي

عند الفتح يقرأ التطبيق `version.json` من هذا المستودع ويقارنه بـ `APP_VERSION`. إن وُجدت نسخة أحدث يظهر شريط في الأعلى. يُرفع الإصدار في `config.py` و`version.json` و`CONFIG.version` في الواجهة و`sw.js` معاً (يفحص ذلك `tests/test_ui.py`).

## للمطوّر

- `CONFIG` في أعلى `static/index.html`: الاسم، لوحة OKLCH (فاتح/داكن)، الخطوط، المنصات، الحالات، الترخيص، رابط التحديث. عميل جديد = تعديل CONFIG فقط.
- محوّل منصة جديد: صنف في `platforms/` يرث `base.BasePlatform` ويعرّف `capabilities` و`publish_*`، ثم يُسجَّل في `platforms/__init__.py`. لا يُعدَّل أي كود عام.
- Hooks اختيارية للردود: `recent_comments`، `reply_to_comment`، `send_dm`.
- قواعد التحرير والبنية في `CLAUDE.md`، وخريطة الملفات في `docs/repo-map.md`.
