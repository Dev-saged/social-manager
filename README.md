# مدير حساباتي — نظام إدارة وتفاعل ذكي لوسائل التواصل

تطبيق بايثون يدير حساباتك في انستغرام وفيسبوك و X ويوتيوب: يراقب منشورات الأصدقاء،
يحلل كل بووست بالذكاء الاصطناعي (Thaura API)، يقترح تعليقاً يليق به، وأنت توافق بضغطة.
ينشر محتواك المجدول تلقائياً، وكل شيء من واجهة HTML عربية فخمة على جوالك.

## البنية: خادم بايثون + واجهة HTML
مصمم خصيصاً للتغليف عبر **WebToApp** (نوع المشروع Python): الخادم المحلي (Flask)
يعمل على جهازك، والواجهة static/index.html تتحدث معه عبر REST API محلي فقط (127.0.0.1).
- ملف الدخول: app.py (التسمية التي يتوقعها WebToApp)
- مجلد الواجهة: static/ وفيه index.html (التسمية التي يتوقعها WebToApp)
- الخادم: core/server.py (كل نقاط /api/*)
- الواجهة: static/index.html — ملف واحد بدون أي مكتبات خارجية أو شبكة، يعمل أوفلاين
- بدون منفذ صحيح: عدّل PORT في app.py إذا طلب WebToApp منفذاً محدداً

## التشغيل على الحاسوب (للتطوير)
```bash
pip install -r requirements.txt
cp .env.example .env        # ثم ضع مفتاح Thaura API
python app.py               # ثم افتح http://127.0.0.1:8080 من المتصفح
```

## التغليف إلى APK عبر WebToApp
1. اختر نوع المشروع: Python.
2. ملف الدخول: app.py، والمكتبات تُحل من requirements.txt تلقائياً.
3. المنفذ: 8080 (أو ما يطلبه التطبيق).
4. انتبه: أول تسجيل دخول ليوتيوب يفتح نافذة OAuth، قم به مرة على الحاسوب ثم انسخ
   مجلد البيانات ~/.social_manager إلى جهاز الأندرويد لتفادي إعادة التفويض.

## الفلسفة: تفاعل نصف أوتوماتيكي
المنصات تحظر الأنماط الآلية بسرعة (توقيت ثابت، تعليقات متتالية، مجاملات عامة).
لهذا صُمم النظام هكذا:
1. الأداة تحلل البوست وتقترح تعليقاً **يظهر أنه فهم البوست فعلاً**.
2. لا يُنشر أي تعليق دون موافقتك اليدوية من تبويب "التفاعل".
3. بعد الموافقة يُنشر بعد **تأخير عشوائي واقعي** (3 دقائق إلى ساعة حسب المنصة).
4. حدود ساعة صارمة لكل منصة في `config.py` منعًا لأي سلوك سبام.

## مفتاح Thaura API
من قائمة الحساب ← API ← API Keys. أو أدخله من تبويب "الإعدادات" بالتطبيق مباشرة.
السعر: 0.5 دولار بالمليون توكن إدخال و2 دولار إخراج، أي أن آلاف التعليقات تكلف قروش.

## بيانات الدخول لكل منصة
- **انستغرام (business)**: حساب بيزنس + Meta Developer App، ثم access_token و ig_user_id.
- **انستغرام (personal)**: اسم المستخدم وكلمة المرور (عبر instagrapi، غير رسمي: معدلات منخفضة جداً).
- **فيسبوك**: Page Access Token و page_id من تطبيق Meta Developer.
- **X**: مفاتيح Developer Account من developer.x.com (الباقات المجانية محددة جداً).
- **يوتيوب**: ملف client_secrets.json من Google Cloud (مع تفعيل YouTube Data API v3) في مجلد البيانات ~/.social_manager.

## هيكل المشروع
```
app.py                  نقطة التشغيل (قاعدة البيانات + المجدول + خادم الويب) — اسم ملف الدخول المتوقع من WebToApp
config.py               الإعدادات، الحدود الآمنة لكل منصة
core/
  database.py           SQLite: حسابات، منشورات مجدولة، طابور تعليقات، سجل
  accounts.py           تشفير بيانات الدخول (Fernet + مفتاح محلي)
  ai_engine.py          تحليل البوست + توليد التعليق والمحتوى (Thaura API)
  scheduler.py          مجدول الخلفية: نشر منشورات + إطلاق تعليقات موافق عليها
  interaction.py        محرك المراقبة والاقتراح (لا ينشر دون موافقتك)
  server.py             خادم Flask: REST API محلي تستهلكه الواجهة
platforms/
  base.py               الواجهة المشتركة + محدودية المعدل
  instagram.py / facebook.py / x_twitter.py / youtube.py
static/
  index.html            واجهة HTML عربية RTL فخمة (ملف واحد، تعمل أوفلاين) — مجلد static المتوقع من WebToApp
```

## أفكار تطوير لاحقة
- إحصاءات تفاعل لكل تعليق (إعجابات على التعليق نفسه) لقياس أي أسلوب يعمل أفضل.
- تعلم أسلوبك: بعد كل موافقة/رفض، تغذية راجعة لصياغة الاقتراحات القادمة.
- جدولة بأوقات الذروة المحسوبة من نشاط جمهورك.
- رفع الصور للانستغرام الشخصي وتحويل روابط الصور إلى base64 للتحليل البصري.
- نسخة احتياطية مشفرة لقاعدة البيانات.

## تنبيه أخلاقي وتشغيلي
الأداة مبنية لتضخّم حضورك أنت بأسلوبك أنت، لا لتنتج حساب سبام. التزم بالحدود في
config.py، ولا تحوّل الموافقة اليدوية إلى موافقة عمياء، فحساباتك هي الرهان.
